# Modelado y simulación del crecimiento de una colonia de hormigas

## Descripción

Este proyecto consiste en el desarrollo de un **modelo matemático y computacional del crecimiento de una colonia de hormigas**, utilizando como variables principales:

* **Hormigas trabajadoras**
* **Larvas**
* **Reinas**

El modelo busca representar, de manera simplificada, cómo cambia la composición de una colonia a lo largo del tiempo y estudiar las condiciones bajo las cuales una colonia puede **dividirse en dos colonias independientes**.

El propósito no es reproducir el comportamiento de una especie de hormiga en particular, sino construir un modelo que permita estudiar la relación entre el crecimiento poblacional de la colonia y su capacidad de generar una nueva colonia.

---

## Objetivo

El objetivo principal es determinar bajo qué condiciones una colonia puede alcanzar un estado en el que resulte posible su **partición en dos colonias**.

Para ello, se estudia la evolución temporal de:

$$
W(t) = \text{número de hormigas trabajadoras}
$$

$$
L(t) = \text{número de larvas}
$$

$$
Q(t) = \text{número de reinas}
$$

A partir de estas variables se pueden analizar diferentes escenarios de crecimiento y determinar cómo factores como la cantidad de trabajadoras, la disponibilidad de larvas y el número de reinas afectan la posibilidad de formar una nueva colonia.

## Hipótesis

La hipótesis general del modelo es:

> **La probabilidad o posibilidad de división de una colonia aumenta cuando la colonia dispone de suficientes individuos reproductivos y trabajadores para mantener tanto la colonia original como una nueva colonia.**
